# Meu Controle Financeiro — V1.12

Aplicativo web de controle financeiro com sincronização via Supabase.

## Publicação

Os arquivos da aplicação ficam na raiz do repositório. O arquivo `config.js`
contém somente a URL pública do projeto Supabase e a chave **Publishable**.

**Não adicionar chaves `sb_secret_...` ou outras credenciais privadas ao repositório.**

## Arquivos principais

- `index.html` — aplicação
- `config.js` — configuração pública do Supabase
- `sw.js` — service worker/cache
- `manifest.json` — configuração do aplicativo
- `logo.png` — identidade visual
